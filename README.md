# Personal Budget App

אפליקציית ניהול תקציב אישי - מעקב הכנסות והוצאות, תקציבים ויעדי חיסכון.

## התקנה

1. שכפלו את הריפו לתיקיית השרת שלכם (למשל `htdocs` ב-XAMPP):
   ```
   git clone <repo-url> project
   ```

2. הפעילו MySQL ו-Apache (למשל דרך XAMPP).

3. אין צורך ליצור את מסד הנתונים ידנית - הוא נוצר אוטומטית (טבלאות + נתוני seed) בקריאה הראשונה לשרת, דרך `sql/init_db.php`.

4. במידת הצורך עדכנו את פרטי החיבור למסד הנתונים בקובץ `config/db.php` (ברירת מחדל: `root` ללא סיסמה).

5. פתחו בדפדפן:
   ```
   http://localhost/project/index.html
   ```

## דרישות
- PHP 7.4+
- MySQL 5.7+
- Apache (מומלץ דרך XAMPP)
